- Timings: warm cache, two warmups, 25 measured iterations per layer. Sequential variants, not statistically randomized. SQL prepared once. No perf/strace/allocation counters during final timings.
- CLI verification: two warmups, 15 measured subprocess invocations, output /dev/null. 40.918 ms median.
- Scan governor installed at foreground duty 1.0, same as fsql; default Scan has no anchors, anchored variant budget 100000 (fixture fits comfortably).
- Count modes avoid collecting full paths; path modes collect paths uniformly via the existing traversal benchmark helpers. Do not compare those modes as identical operations.
- Probe requires expected result counts. Existing and direct JSON serializer outputs additionally compared as full path multisets, including special filenames.
- query-direct is a deliberately specialized experiment for one text path column, not a production-ready replacement for all output types.

## Reproducing future measurements

Use [the repository layer probes](../layers.md), not the original temporary Cargo package. The new probes include query preparation per iteration, use an anchor budget of 1024, validate complete path multisets, and report stats_alloc counters with reallocations separate. Their generated fixture has a different shape. Historical numbers above are therefore evidence of the original investigation, not directly interchangeable baselines for the new harness.
